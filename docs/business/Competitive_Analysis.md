# 竞品分析报告

## 一、 分析背景
本项目定位为“基于普通摄像头的桌面学习体态提醒工具”，面向学生群体（尤其是大学生和青少年），在家庭/宿舍学习场景中实时监测并纠正不良体态。为明确差异化优势，现对市场上已有的同类产品与开源项目进行系统分析。

## 三、 竞品共性缺陷

1. **场景固化**：绝大多数竞品聚焦于“运动健身”或“临床康复”场景，缺乏对“日常学习静坐”场景的关注。
2. **技术过重**：多个竞品依赖深度学习模型训练（BiLSTM、ResMLP），需要大量标注数据和GPU算力，部署门槛高。
3. **硬件依赖**：商业方案通常需要专用摄像头或传感器，无法利用学生已有的笔记本电脑摄像头。
4. **缺乏正向激励**：多数工具以“报警/纠正”为核心逻辑，容易引发用户抵触，缺少鼓励机制。

## 四、 本项目差异化定位

### 4.1 场景差异化：书桌前的“体态守望者”
- **不做运动纠正**，专注于**静态学习体态**（头前倾、圆肩、驼背）。
- **不做事后评估**，专注于**实时监测与温和提醒**。
- **不做B端校园方案**，专注于**个人桌面工具**，零硬件成本。

### 4.2 技术差异化：轻量化几何计算路线
- 基于 MediaPipe 提取的 33 个关键点，通过**关节夹角几何计算**判断体态。
- **无需训练数据，无需GPU**，普通笔记本即可流畅运行。
- 相比PosePilot等深度学习方案，部署成本极低，迭代速度快。

### 4.3 产品差异化：无感提醒 + 正向激励
- **三级反馈机制**：视觉弱提醒（屏幕边缘变色）→ 声音轻提醒 → 强制休息，避免打扰学习心流。
- **正向激励系统**：保持正确体态积累积分，解锁成就，把“被监督”变成“自我成长”。
- **可选番茄钟整合**：将体态检测与学习时间管理结合，提升产品粘性。

### 4.4 部署差异化：离线可用的独立桌面软件
- 打包为 Windows 独立应用（后续可扩展至 Mac/Linux）。
- 无需联网，无需注册，打开即用，隐私数据本地处理。
- 适合在宿舍、图书馆、家庭学习场景中随时使用。

## 五、 结论
当前市场上已有基于MediaPipe的桌面体态工具（如PostureGuard），但它们多以系统弹窗或主窗口反馈作为主要交互方式。本项目精准切入这一赛道中的“极致无感”空白：通过常驻悬浮窗的颜色变化替代弹窗通知，在不打断用户心流、不显示任何画面数据的前提下，实现更温和、更符合生理直觉的体态提醒。
