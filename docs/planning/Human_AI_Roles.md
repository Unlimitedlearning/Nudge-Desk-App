# 人机分工说明

## 我的核心职责（创始人/架构师）

- **产品定义**：决定做什么（比如防近视、无感悬浮窗），不做什么（不搞强弹窗、不增加繁琐的按钮）

- **系统架构**：决定用哪几个模块（输入→视觉→分析→表现），决定数据如何流转。

- **算法逻辑**：定义三维中轴点、滑动窗口去噪、以及独创的“疲劳值积分回血机制”和防误报阈值。

- **工程决策**：决定使用 tkinter 而非 PyQt，决定用 root.after 而非多线程。

- **验收与测试**：亲自运行程序，发现“一低头就变黄”的体验问题，并决定修改阈值。

- **版本控制与文档**：用Git进行提交，记录开发日志，撰写竞品分析。

## AI的职责（技术助手/结对程序员工作）

- **代码翻译**：把我说出的“取三维中点坐标”翻译成具体的 for 循环和数学公式代码。

- **语法解释**：解释 deque、math.acos、tkinter 回调等底层语法。

- **错误排查**：告诉我 comfidence 拼错了、KeyError 是因为字典嵌套了。

- **文档润色**：帮我把“感觉挺卡的”润色成“存在性能瓶颈，需引入时间窗口”。

## 我未来需要注意（防止依赖）

- **先思考，后提问**：遇到报错，先自己看报错行数，猜一下原因，再去查或问AI。

- **主动注释**：在AI生成的代码上，加上自己理解的注释，消化实现逻辑。
