# 项目开发路线图 (Roadmap)

## 🎯 一、 核心目标
开发一款**面向学生群体、基于普通摄像头、可离线运行、保护隐私**的桌面学习体态提醒工具。

## 🏗️ 二、 技术架构
采用分层设计，各模块解耦，便于独立测试与迭代：
1. **输入层**（`src/camera.py`）：摄像头采集。
2. **视觉层**（`src/pose.py`）：MediaPipe 骨骼提取（33个关键点）。
3. **分析层**（`src/analysis.py`）：三维中轴点提取 + 耳肩髋夹角计算 + 滑动窗口平滑。
4. **表现层**（`src/ui.py`）：桌面悬浮窗/屏幕边缘变色提醒（待开发）。

### 阶段五：V2.0 架构演进蓝图（长期规划 ⏳）
基于指导老师的建议，本项目未来的演进方向将从“单体检测工具”升级为“可扩展的体态识别引擎”：
- [ ] **构建三库分层架构**：独立出“姿态库”、“动作库”和“语义库”（类病毒库动态扩展机制），让算法可动态适应新姿态与自定义行为。
- [ ] **探索“行为语义识别”**：从目前的几何姿态识别，逐步向“关节点→姿态→动作→不良语义”演进，、将几何数据提炼为高层应用逻辑。
- [ ] **模块并发设计**：梳理各模块间的同步/异步关系，明确线程级和模块级的边界，提升系统多任务处理能力。

## ⚠️ 当前局限性
- 单人独立开发，算力限于普通笔记本，暂未引入深度学习模型。
- 2D摄像头在复杂光线/多人场景下鲁棒性有限。
