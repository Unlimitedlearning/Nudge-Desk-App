# 产品愿景 (Product Vision)

## 核心交互原则
主打**简约、余光感知、静默无扰**的体验，在不为用户增加认知负担的前提下，完成体态提醒。

## UI设计构想
- **初始形象**：圆角矩形的“果冻”，有一定的凹凸立体感。
- **日常状态**：平时不显示字体干扰，仅靠颜色渐变传达状态。
- **交互方式**：只有鼠标悬停时，才显示详细状态（比如 正常/低头过久/高低肩）

## 未来商业方向（暂不开发）
- **C端增值**：简笔画动物皮肤（买断制，价格亲民，核心功能不收费）。
- **B端授权（远期）**：待算法成熟后，考虑授权给硬件厂商（如护眼台灯、人体工学椅）作为附加卖点。
