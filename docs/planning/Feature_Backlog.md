# 未来待办（Feature Backlog）

## 一、 功能扩展
- [x] **防近视**：防止用户脸和电脑贴得太近而毫无察觉。
- [x] **高低肩检测**：提醒用户是否坐歪。
- [ ] **番茄钟联动**：每25分钟强制提醒休息，并统计疲劳值。

## 二、 体验优化
- [ ] **髋部视角受限问题**： 用“鼻-肩-髋”算夹角，如果用户髋部在摄像头范围外，会导致低头检测出现问题。考虑采用“降级方案”解决，即出现此情况时启用另一种识别方式代替“计算鼻-肩-髋夹角”。
- [x] **声音轻提醒**：当疲劳值达到ALERT阈值时，播放提示音。
- [ ] **透明度动态变化**：根据疲劳值实时改变悬浮窗透明度（越疲劳越显眼）。
- [ ] **姿态识别**：调试程序，改进检测阈值。
- [x] **个性化校准**：不同用户的身高、桌面高度、屏幕倾角均不同。因此“一键校准”功能（让用户保持自己最舒服的端正坐姿3秒钟，记录为基线，以此基线为准判定低头，而非固定角度）
