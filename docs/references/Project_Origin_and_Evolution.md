# 项目演进记录：从体态识别技术到体态纠正工具

## 一、 技术积累与前期探索（2026年9月）
在开学军训期间，我参与了“非遗文化+AI动作识别”初创项目的初期筹备工作。在此期间，完成了以下实质性基础工作：
1. **团队架构统筹**：起草并完成了两版团队分工方案。
2. **系统架构设计**：设计了项目的底层技术架构（输入层→骨骼提取层→动作识别层→表现层）。
3. **技术选型预研**：主导评估了 YOLO 与 MediaPipe 在动作识别场景下的优劣，确认以 Camera + MediaPipe 作为初期核心方案。
4. **进度规划**：根据项目初期节点，倒推制定了“跑通Demo”的里程碑。

## 二、 战略转型与独立重构（2026年9月中旬）
在项目推进过程中，因个人身体健康原因需要休整，以及出于对“系统化工程与模块化开发”的技术理念追求，我选择调整原定计划，沉淀并独立开启新的项目征程。

经过复盘，我发现原有的底层技术架构逻辑（视频流输入 → 骨架提取 → 动作比对 → 判定逻辑）具有极高的可复用性，不仅限于娱乐领域。结合大一新生久坐、体态不良、缺乏科学指导的现实痛点，我决定将技术应用方向从“游戏娱乐”转向“教育健康”，独立开发《体育体态纠正工具》。
