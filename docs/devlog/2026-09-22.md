# 2026年9月21日 开发日志

## 核心进展：成功打包桌面应用
经过昨晚，今早数小时尝试，最终采用 Nuitka 成功打包桌面应用。核心踩坑记录：

PyInstaller 无法正确加载 MediaPipe 底层 C++ 库，全线失败。

Nuitka 编译时成功自动下载 C++ 编译器，但需手动授权。

关键Bug：打包后启动闪退，报错 pose_landmark_cpu.binarypb 缺失。原因是 Nuitka 不会自动打包 MediaPipe 的模型文件。解决方案：将虚拟环境 .venv 里的 mediapipe/modules 文件夹，手动复制到 app.dist/mediapipe/ 目录下，问题解决！

最终实现了无需源码、双击即用的绿色版分发。
